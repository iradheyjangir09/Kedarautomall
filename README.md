# Kedar Automall

## About the Project

I built Kedar Automall as a website for a pre-owned car business. Visitors can browse vehicles, check their details and prices, and find the business’s contact information. I focused on making the design clean and easy to use on both desktop and mobile screens.

## Live Website

[Visit Kedar Automall](https://kedarautomall.vercel.app/)

## Pages and Sections

The project currently has one page, `index.html`, with these sections:

- Home
- Browse by Style
- Featured Vehicles
- Services
- About Us
- Contact

## Technologies Used

- HTML
- Tailwind CSS
- AOS for scroll animations
- Font Awesome for icons

## Features

- Responsive layout
- Vehicle cards with details and prices
- Services and About sections
- Contact section with a form layout
